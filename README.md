# 🏋️ Gym FAQ Chatbot

An AI-powered chatbot that answers Frequently Asked Questions about gym memberships, facilities, and services using Natural Language Processing.

## Features
- Real-time question matching using Cosine Similarity
- 32 comprehensive gym FAQs
- Clean web interface with Flask
- Confidence scoring for answer accuracy
- Mobile-responsive design

## Tech Stack
- Python, Flask, NLTK, Scikit-learn, Pandas

## Installation
1. Clone the repository
2. Create virtual environment: `python -m venv venv`
3. Activate: `venv\Scripts\activate`
4. Install: `pip install -r requirements.txt`
5. Run: `python app/main.py`

## Usage
Open browser and go to `http://localhost:5000`
